# NGO CRM — wersja chmurowa

Lekki, modułowy CRM dla polskich organizacji pozarządowych (stowarzyszenia, fundacje), działający w przeglądarce. Każda organizacja instaluje go na **własnym hostingu**; autor programu nie ma dostępu do danych.

**Status:** projekt w fazie koncepcji, kod jeszcze nie powstał.

- Najważniejsze dane (PESEL, orzeczenia, zdrowie, wszystkie pliki) szyfruje przeglądarka. Serwer nie ma klucza.
- Konto i 2FA dla każdej osoby, uprawnienia, dziennik dostępu.
- Kopie z poziomu aplikacji i klucz odzyskiwania do wydruku.
